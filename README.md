# RUN CLEMANTINE, RUN!

A Phaser 3 endless runner. Play as Shawgi, dodge obstacles and outrun Forelli, Felix, Sahar and the Helicopter across four phases.

## Play
Serve the folder with any static server (audio/images won't load from `file://`), e.g.

```
npx serve .
```

then open the printed URL. Also works on GitHub Pages.

## Controls
- **Space** – jump (double jump)
- **↓ / Shift** – slide
- **D** – throw clementine
- **← / →** – adjust speed
- **S** – heal, **A** – mega boost
